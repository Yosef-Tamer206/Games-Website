# GameArena - Games Website

A gaming community landing site: hero, games showcase, community call-to-action, newsletter signup and contact.

**Live demo:** https://yosef-tamer206.github.io/Games-Website/

![Games-Website screenshot](docs/screenshot.png)

## Features

- Hero section with bold gaming artwork
- Games showcase section
- "Join Our Community" section with newsletter email signup
- Contact section with message form, phone and location info
- Responsive layout with a dedicated media-query stylesheet

## Tech Stack

- HTML5
- CSS3 (custom styles plus responsive `media.css`)
- Bootstrap 5
- Font Awesome icons

## Run Locally

```bash
git clone https://github.com/Yosef-Tamer206/Games-Website.git
cd Games-Website
```

Open `index.html` in a browser.

## Notes

- Front-end only. The signup and contact forms are UI only; nothing is sent anywhere.
